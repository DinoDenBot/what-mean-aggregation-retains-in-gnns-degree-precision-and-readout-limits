# What Mean Aggregation Retains in GNNs: Degree, Precision, and Readout Limits

This repository contains reproduction code, fixed configurations, and the
checkpoint inputs needed for the frozen-model intervention. It contains no
manuscript source or rendered paper. All data generated by the experiments are
synthetic.

## Check the code

Install Python 3.12 and `uv`, then run:

```sh
sh verify.sh
```

This runs the categorical and Gaussian calculation tests, the finite-depth
mechanical checks, the finite-CSBM exact-ratio calculation, and CPU interface
tests for the trained-model studies. It does not run the full training jobs.

## Reproduce the reported calculations

The commands below write to new output directories. `SPEC.md` and `config.json`
inside each study fix its sampling law, seeds, model settings, and decision
rules.

| Calculation | Code | Command |
|---|---|---|
| Exact and perturbed categorical ratios; Gaussian mean | `theory-code/` | `sh verify.sh` |
| Quadratic readout asymptotics | `regular-readout-asymptotics/` | See CPU commands below |
| Categorical precision, partitions, and fitted probes | `unified-precision-experiment/` | See CPU commands below |
| Finite-depth quantized mean | `depth-score-geometry/` | `sh reproduce_depth.sh full /tmp/depth-run` |
| Finite-CSBM exact label-ratio bound | `finite-csbm-experiment/exact_ratio_fisher.py` | `sh verify.sh` |
| Finite-CSBM smooth-probe study | `finite-csbm-experiment/` | GPU command below |
| Trained CSBM transfer | `inductive-csbm-transfer-experiment/` | GPU command below |
| Frozen-model precision and noise intervention | `precision-intervention-experiment/` | CPU command below |

CPU runs:

```sh
mkdir /tmp/regular-readout-run
cp regular-readout-asymptotics/run.py regular-readout-asymptotics/verify.py \
  regular-readout-asymptotics/SPEC.md /tmp/regular-readout-run/
uv run --python 3.12 --with numpy==2.5.2 --with scipy==1.18.1 \
  python /tmp/regular-readout-run/run.py
uv run --python 3.12 --with numpy==2.5.2 --with scipy==1.18.1 \
  python /tmp/regular-readout-run/verify.py

uv run --python 3.12 --with numpy==2.5.2 --with scipy==1.18.1 \
  --with torch==2.14.0 bash unified-precision-experiment/reproduce.sh \
  /tmp/unified-precision-run

sh reproduce_depth.sh full /tmp/depth-run

uv run --python 3.12 --with torch==2.8.0 --with numpy==2.1.2 \
  python -c 'import torch, numpy'
sh precision-intervention-experiment/reproduce.sh /tmp/intervention-run
```

The intervention runner uses `uv` offline, so the preceding command caches
its pinned packages. Its `inputs/` directory holds the frozen models and
baseline graph metrics required for the paired intervention. The runner checks
their digests and refuses to overwrite an existing output directory.

For the trained finite-CSBM and transfer studies, use the PyTorch 2.8 and
NumPy 2.1 environment specified in each `bundle/requirements.txt`. A GPU makes
the full runs practical:

```sh
PYTHON_BIN=python bash finite-csbm-experiment/reproduce.sh full /tmp/finite-csbm-run
PYTHON_BIN=python bash reproduce_inductive_transfer.sh full /tmp/csbm-transfer-run
```

The earlier finite-precision and coarsening curves cannot be rerun from this
code: their original generator and intermediate input were absent from the
available artifact. The unified precision study independently reruns related
arithmetic channels. Do not treat it as a byte-for-byte regeneration of those
earlier curves.
